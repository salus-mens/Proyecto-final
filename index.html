PROYECTO FINAL: GIT + HTML/CSS

Este es un proyecto final de la materia de GIT + HTML/CSS, en el cual se muestra la estructura básica de un sitio web utilizando HTML y CSS. Se incluyen secciones como inicio, sobre nosotros, video y mapas, con enlaces de navegación para facilitar el acceso a cada sección.
